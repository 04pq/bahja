بهجة V3 — دليل التشغيل والتعديل
(تصميم جديد بالكامل: بيج فاتح هادئ. المنتجات والأسعار والأوصاف والنصوص كما هي بدون أي تغيير)
================================

1) تشغيل الموقع
- فك ضغط مجلد bahja_v2.
- افتح index.html في المتصفح، أو ارفع كامل محتويات المجلد إلى الاستضافة.
- لا تحذف مجلد imgs؛ جميع الصور مرتبطة بالمسارات الموجودة فيه.
- الموقع HTML / CSS / JavaScript ولا يحتاج قاعدة بيانات لتجربة السلة والمفضلة.
- السلة والمفضلة تحفظان في متصفح العميل باستخدام localStorage.

2) ملفات المشروع
- index.html       الصفحة الرئيسية والمتجر والسلة ونموذج الطلب.
- about.html       صفحة من نحن.
- support.html     صفحة الدعم الفني والأسئلة الشائعة.
- style.css        جميع الألوان والتنسيقات والتجاوب مع الشاشات.
- products.js      أسماء المنتجات والأسعار والأوصاف ومسارات صورها.
- app.js           السلة والمفضلة والبحث والتفاصيل وإرسال الطلب عبر واتساب.
- imgs/            جميع صور الشعار والمنتجات والبنرات.

3) الرقم الذي يستقبل الطلبات
افتح app.js وابحث عن:
whatsapp: "966555555555"
غيّره إلى رقم واتساب الحقيقي بصيغة دولية بدون + أو مسافات.
مثال للسعودية: 9665XXXXXXXX
يوجد كذلك رابط الرقم في about/support/index داخل الفوتر، فحدّثه هناك أيضاً عند تغيير الرقم.

ملاحظة مهمة: الرقم الحالي 0555555555 تجريبي. رابط واتساب يستخدم الصيغة الدولية 966555555555.

4) الأسعار والأوصاف
افتح products.js:
- غيّر price: 0 إلى السعر بالريال، مثال price: 45
- غيّر description إلى وصف المنتج الصحيح.
- لا تترك السعر صفراً عند استقبال طلبات فعلية؛ الموقع يمنع إرسال طلب واتساب إذا كان في السلة منتج بلا سعر.

6) تنبيهات مهمة قبل الإطلاق
- تأكد من أن أسماء الصور مطابقة تماماً للأسماء أعلاه، بما فيها الحروف والأرقام.
- صورة الفاتوران الأصفر المعتمدة هي ftr_a9fr وليس ftr_ahmr.
- الصور الخمس لكل منتج تظهر في معرض الصور عند فتح المنتج.
- أضف الأسعار والمواصفات الحقيقية قبل استقبال طلبات العملاء.
- إرسال الطلب يفتح واتساب برسالة مجهزة؛ العميل يضغط إرسال داخل واتساب بنفسه. هذا ليس دفعاً إلكترونياً أو تحصيلاً آلياً للمبلغ.
- الموقع الحالي واجهة متجر ثابتة؛ لا يوجد مخزون مركزي أو لوحة تحكم أو إشعارات طلبات للخادم.


7) ملاحظات V3
- كل الألوان في أعلى style.css داخل :root (--bg البيج الأساسي، --brick القرميدي، --navy الكحلي، --gold الذهبي).
- تم تخفيف حجم الصور (نفس الأسماء والمحتوى) لتسريع تحميل الموقع.
- الخطوط (Reem Kufi + IBM Plex Sans Arabic) تُحمّل من Google Fonts وتحتاج إنترنت.
